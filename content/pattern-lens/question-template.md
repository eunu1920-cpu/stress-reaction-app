# Pattern Lens Question Template

아래 형식으로 텍스트를 보내면 바로 코드 구조로 옮기기 쉽습니다.

주의:
- `질문 ID`는 `stress_002`, `relation_002`, `self_002`처럼 적습니다.
- `상태`는 보통 `active`를 사용합니다.
- `포인트`는 짧은 문구 3개 정도로 적습니다.
- `**강조**` 같은 마크다운은 현재 화면에서 굵게 렌더링되지 않습니다.

```text
카테고리: stress
질문 ID: stress_002
버전: 1
상태: active

상황:
시작도 끝도 없다. 업무가 쌓일 때

프롬프트:

해석 본문:
```
